# Contributing

Contributions are welcome. Keep changes focused on the `tffax` module, preserve FreePBX 16/17 compatibility, and avoid introducing dependencies on private or commercial modules.

Before submitting changes:

```bash
find . -name '*.php' -print0 | xargs -0 -n1 php -l
```

Please include a concise description of the problem, test environment, and validation steps.

Author/maintainer contact: Tommy Heggie <tommy@techfinity.tech>.
