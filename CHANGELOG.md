# Changelog

## 16.0.2 - 2026-08-21

First complete public source release based on the tested 0.4.8 codebase.

- Removed private product/company branding and platform-module coupling.
- Preserved multi-user inbound/outbound fax workflow.
- Preserved DID/CID routing and unassigned-inbox behavior.
- Preserved user portal, cover pages, previews, email notifications, test fax, caller-ID request, timezone handling, themes, and diagnostics.
- Changed the default spool path to `/var/spool/asterisk/tffax`.
- Updated metadata and documentation for FreePBX 16/17 public distribution.
